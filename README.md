# C++ Demo

A minimal Docker image demonstrating how to compile and run a simple C++ program.

## Pull

```bash
docker pull semdevinc/cpp-demo
```

## Run

```bash
docker run -it --rm semdevinc/cpp-demo
```

## Files

- Dockerfile
- main.cpp
- run.sh
